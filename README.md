# java-lotto-precourse

## 로또 발매기

로또를 구입하기 위해 돈을 입력하면, 금액에 맞춰 로또가 발행됩니다.
로또의 당첨 번호 및 보너스 번호는 사용자의 입력을 받아 정하며, 구입한 로또의 번호와 비교합니다.
이후 당첨 통계와 수익률을 함께 보여줍니다.

## 프로그램 실행 흐름

로또 1장의 가격은 1,000원입니다. 로또 8장을 구매하기 위해 8,000원을 입력합니다.

```
구입금액을 입력해 주세요.
8000
```

만약 잘못된 값을 입력하게 될 경우, 에러 메세지가 표시되며 다시 입력하도록 안내 메세지가 나옵니다.

```
구입금액을 입력해 주세요.
2025-11-03
[ERROR] 입력은 양의 정수여야 합니다.
구입금액을 입력해 주세요.
```

8개의 로또를 구매하였습니다. 로또 발매기가 자동으로 6개의 숫자가 적힌 8장의 로또를 출력합니다.

```
8개를 구입했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```

이제 당첨 번호의 입력을 받습니다. 6개의 숫자를 쉼표(`,`)로 구분하여 입력합니다.

```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```

만약 잘못된 값을 입력하게 될 경우, 에러 메세지가 표시되며 다시 입력하도록 안내 메세지가 나옵니다.

```
당첨 번호를 입력해 주세요.
1,2,3,111
[ERROR] 입력은 1부터 45사이의 정수여야 합니다.

당첨 번호를 입력해 주세요.
```

```
당첨 번호를 입력해 주세요.
1,2,3,4,5,1
[ERROR] 중복된 수가 존재합니다.

당첨 번호를 입력해 주세요.
```

추가로 보너스 번호의 입력을 받습니다.

```
보너스 번호를 입력해 주세요.
7
```

만약 잘못된 값을 입력하게 될 경우, 에러 메세지가 표시되며 다시 입력하도록 안내 메세지가 나옵니다.

```
보너스 번호를 입력해 주세요.
-1
[ERROR] 입력은 양의 정수여야 합니다.

보너스 번호를 입력해 주세요.
```

```
보너스 번호를 입력해 주세요.
1
[ERROR] 중복된 수가 존재합니다.

보너스 번호를 입력해 주세요.
```

구매한 로또의 개수와 입력한 당첨 번호 및 보너스 번호를 이용하여 당첨 통계와 총 수익률을 보여줍니다.

```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능 목록

### 로또 구입 금액 입력받기

- 1,000원 단위로 입력
- 입력 예시

  ```
  14000
  ```

- 예외 조건
  - 1,000원 단위로 떨어지지 않는 경우
  - 양의 정수가 아닌 경우

### 구입한 로또 번호 구하기

- 6개의 랜덤 숫자 추출
  랜덤값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickUniqueNumbersInRange()`를 활용
- 구입한 로또의 개수만큼 구함

- 숫자의 범위는 `1~45`

### 구입한 로또 번호 출력

- 구입한 로또의 개수만큼 출력
- 출력 예시
  ```
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  ```

### 당첨 번호 및 보너스 번호 입력받기

- 중복되지 않는 6개의 숫자를 쉼표(`,`)로 구분하여 입력
- 보너스 번호 또한 숫자로 입력
- 숫자의 범위는 `1~45`
- 입력 예시
  ```
  1,2,3,4,5,6
  ```
  ```
  7
  ```
- 예외 조건
  - 입력된 당첨 번호가 양의 정수가 아닌 경우
  - 입력된 당첨 번호의 개수가 6개가 아닌 경우
  - 입력된 당첨 번호에 중복된 수가 있는 경우

### 당첨 확인

- 당첨 기준에 맞춰 구입한 로또의 당첨 금액을 확인

### 수익률 확인

- 구입한 로또의 개수와 당첨 금액을 이용하여 수익률 확인
- 수익률은 소수점 둘째 자리에서 반올림 (ex. 100.0%, 51.5%, 1,000,000.0%)

### 결과 출력

- 당첨된 로또의 개수 출력
- 총 수익률을 출력

### 예외 상황 시 에러 문구 출력

- 출력 예시
  ```
  [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  ```
