# java-lotto-precourse

## 로또 발매기

로또를 구입하고 당첨 결과를 확인한다.  
구입 금액에 따라 로또를 발행하며, 당첨 번호 및 보너스 번호를 입력받아 수익률을 계산한다.  
로또 1장의 가격은 1,000원이다.

- 실행 결과 예시

```
구입금액을 입력해 주세요.
8000

8개를 구입했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능 목록

### 로또 구입 금액 입력받기

- 1,000원 단위로 입력
- 입력 예시

  ```
  14000
  ```

- 예외 조건
  - 1,000원 단위로 떨어지지 않는 경우
  - 양의 정수가 아닌 경우

### 구입한 로또 번호 구하기

- 6개의 랜덤 숫자 추출
  랜덤값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickUniqueNumbersInRange()`를 활용
- 구입한 로또의 개수만큼 구함

- 숫자의 범위는 `1~45`

### 구입한 로또 번호 출력

- 구입한 로또의 개수만큼 출력
- 출력 예시
  ```
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  ```

### 당첨 번호 및 보너스 번호 입력받기

- 중복되지 않는 6개의 숫자를 쉼표(`,`)로 구분하여 입력
- 보너스 번호 또한 숫자로 입력
- 숫자의 범위는 `1~45`
- 입력 예시
  ```
  1,2,3,4,5,6
  ```
  ```
  7
  ```
- 예외 조건
  - 범위를 벗어난 숫자가 존재하는 경우
  - 숫자가 아닌 값을 입력한 경우

## 구현 예정 기능 목록

### 당첨 확인

- 당첨 기준에 맞춰 구입한 로또의 당첨 금액을 확인

### 수익률 확인

- 구입한 로또의 개수와 당첨 금액을 이용하여 수익률 확인
- 수익률은 소수점 둘째 자리에서 반올림 (ex. 100.0%, 51.5%, 1,000,000.0%)

### 결과 출력

- 당첨된 로또의 개수 출력
- 총 수익률을 출력

### 예외 상황 시 에러 문구 출력

- 출력 예시
  ```
  [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  ```
